# Form Card 表单卡片

表单卡片按业务主题组织字段，建立清晰的信息层级。

## 使用建议

- 卡片不接管内部字段校验。
- 操作区通过 action 插槽承载轻量辅助操作。

## API

| 属性        | 类型    | 默认值 | 说明         |
| ----------- | ------- | ------ | ------------ |
| title       | string  | -      | 卡片标题     |
| description | string  | -      | 卡片说明     |
| bordered    | boolean | true   | 是否显示边框 |
