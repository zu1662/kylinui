# Form Card 表单卡片

Form Card 按业务主题组织字段，建立清晰的信息层级，并为标题、辅助操作和表单内容提供稳定容器。

## 使用建议

- 卡片只负责分组和层级，不接管内部字段校验或提交状态。
- 操作区通过 `action` 插槽承载轻量辅助操作。

## API

| 属性        | 类型      | 默认值 | 说明         |
| ----------- | --------- | ------ | ------------ |
| title       | `string`  | -      | 卡片标题     |
| description | `string`  | -      | 卡片说明     |
| bordered    | `boolean` | `true` | 是否显示边框 |

## 插槽

| 名称    | 说明                       |
| ------- | -------------------------- |
| header  | 自定义标题和说明区域       |
| action  | 标题区域右侧的辅助操作     |
| default | 表单字段或其他卡片主体内容 |
