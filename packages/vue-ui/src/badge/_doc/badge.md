# Badge 徽标

Badge 用于在图标或内容旁展示数量、短文本或状态点，适合消息提醒、待办数量和轻量状态提示。

## 使用建议

- 数量超过上限时使用 `max` 收敛展示长度，避免遮挡主体内容。
- 仅表达状态时使用圆点模式，不要只依赖颜色传递关键信息。

## API

| 属性     | 类型                                                           | 默认值        | 说明                 |
| -------- | -------------------------------------------------------------- | ------------- | -------------------- |
| content  | `string \| number`                                             | `''`          | 徽标内容             |
| max      | `number`                                                       | `99`          | 数值内容的最大展示值 |
| dot      | `boolean`                                                      | `false`       | 是否显示为圆点       |
| showZero | `boolean`                                                      | `true`        | 内容为 0 时是否显示  |
| position | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | 徽标相对主体的位置   |
| color    | `string`                                                       | `''`          | 自定义徽标颜色       |
| offset   | `[number \| string, number \| string]`                         | `[0, 0]`      | 水平和垂直偏移       |

## 插槽

| 名称    | 说明                             |
| ------- | -------------------------------- |
| default | 被徽标包裹的主体内容             |
| content | 自定义徽标内容，优先于 `content` |
