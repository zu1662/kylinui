# Divider 分割线

Divider 用于分隔内容区块，也可在水平分割线上承载简短说明。

## 使用建议

- 分割线用于辅助内容分组，不应替代明确的标题层级。
- 垂直分割模式不展示默认插槽内容。

## API

| 属性            | 类型                            | 默认值     | 说明                 |
| --------------- | ------------------------------- | ---------- | -------------------- |
| dashed          | `boolean`                       | `false`    | 是否使用虚线         |
| hairline        | `boolean`                       | `true`     | 是否使用细线         |
| contentPosition | `'left' \| 'center' \| 'right'` | `'center'` | 内容在分割线中的位置 |
| vertical        | `boolean`                       | `false`    | 是否使用垂直分割线   |

## 插槽

| 名称    | 说明                       |
| ------- | -------------------------- |
| default | 水平分割线中显示的说明内容 |
