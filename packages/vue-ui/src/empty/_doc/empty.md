# Empty 空状态

Empty 用于列表、搜索结果或网络异常等无内容场景，向用户说明当前状态并承载后续操作。

## 使用建议

- 根据场景选择默认、搜索、网络或错误图形，并提供明确的描述文案。
- 需要引导用户继续操作时，将按钮或链接放入默认插槽。

## API

| 属性        | 类型                                            | 默认值       | 说明                      |
| ----------- | ----------------------------------------------- | ------------ | ------------------------- |
| image       | `'default' \| 'search' \| 'network' \| 'error'` | `'default'`  | 内置空状态图形            |
| imageSize   | `number \| string`                              | `112`        | 图形尺寸，数字单位为 `px` |
| description | `string`                                        | `'暂无内容'` | 空状态描述                |

## 插槽

| 名称        | 说明                     |
| ----------- | ------------------------ |
| image       | 自定义空状态图形         |
| description | 自定义描述内容           |
| default     | 描述下方的操作或补充内容 |
