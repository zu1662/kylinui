# NoticeBar 通知栏

NoticeBar 用于在页面内展示重要但非阻断性的通知，支持关闭、跳转、多行和横向滚动场景。

## 使用建议

- 通知内容应简短明确，避免在通知栏中承载复杂操作。
- 可关闭通知由业务负责记录关闭状态；链接模式通过 `click` 事件处理后续行为。
- 使用默认插槽自定义内容时，内容宽度变化会自动重新测量并启用或停止横向滚动。

## API

| 属性       | 类型                          | 默认值      | 说明                       |
| ---------- | ----------------------------- | ----------- | -------------------------- |
| text       | `string`                      | `''`        | 通知文字                   |
| mode       | `'' \| 'closeable' \| 'link'` | `''`        | 右侧操作模式               |
| color      | `string`                      | `''`        | 文字颜色                   |
| background | `string`                      | `''`        | 背景颜色                   |
| leftIcon   | `string`                      | `'speaker'` | 左侧 KyIcon 图标名称       |
| wrapable   | `boolean`                     | `false`     | 是否允许内容换行           |
| scrollable | `boolean`                     | `true`      | 溢出时是否启用横向滚动     |
| delay      | `number`                      | `1`         | 滚动开始前的延迟，单位为秒 |
| speed      | `number`                      | `60`        | 滚动速度，单位为像素/秒    |

## 事件

| 事件名 | 说明                         | 回调参数 |
| ------ | ---------------------------- | -------- |
| close  | 点击关闭按钮时触发           | -        |
| click  | 点击非关闭模式的通知栏时触发 | -        |

## 插槽

| 名称      | 说明           |
| --------- | -------------- |
| left-icon | 自定义左侧图标 |
| default   | 自定义通知内容 |
