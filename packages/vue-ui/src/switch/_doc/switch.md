# Switch 开关

Switch 用于切换立即生效的二元状态，并可通过尺寸和禁用状态适配不同表单场景。

## 使用建议

- 仅用于会立即生效的设置；需要提交确认时优先使用 Checkbox。
- 标签应描述开启后的状态或控制对象，避免只写“开关”。

## API

| 属性       | 类型                  | 默认值     | 说明     |
| ---------- | --------------------- | ---------- | -------- |
| modelValue | `boolean`             | `false`    | 是否开启 |
| label      | `string`              | 必填       | 开关标签 |
| disabled   | `boolean`             | `false`    | 是否禁用 |
| size       | `'small' \| 'medium'` | `'medium'` | 开关尺寸 |

## 事件

| 事件名            | 说明               | 回调参数         |
| ----------------- | ------------------ | ---------------- |
| update:modelValue | 开关状态变化时触发 | `value: boolean` |
| change            | 用户切换开关时触发 | `value: boolean` |

## 插槽

| 名称    | 说明               |
| ------- | ------------------ |
| default | 自定义开关标签内容 |
