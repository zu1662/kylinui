# Loading 加载

Loading 用于表示局部内容或操作正在处理中，可使用圆环或菊花样式展示等待状态。

## 使用建议

- 持续时间较长的加载应搭配简短文字说明。
- 加载图标作为状态反馈时，容器应同步提供可访问的忙碌状态。

## API

| 属性      | 类型                      | 默认值       | 说明                      |
| --------- | ------------------------- | ------------ | ------------------------- |
| type      | `'circular' \| 'spinner'` | `'circular'` | 加载图标类型              |
| size      | `number \| string`        | `28`         | 图标尺寸，数字单位为 `px` |
| color     | `string`                  | `''`         | 图标颜色                  |
| textColor | `string`                  | `''`         | 文字颜色                  |
| textSize  | `number \| string`        | `14`         | 文字尺寸，数字单位为 `px` |
| vertical  | `boolean`                 | `false`      | 是否垂直排列图标和文字    |

## 插槽

| 名称    | 说明         |
| ------- | ------------ |
| default | 加载提示文字 |
