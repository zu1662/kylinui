# Space 间距

Space 用于统一控制一组元素之间的横向或纵向间距，并支持换行、对齐和填充布局。

## 使用建议

- 优先使用语义化尺寸，保持页面间距节奏一致。
- 复杂二维布局应使用更明确的布局容器，不要依赖 Space 模拟网格。

## API

| 属性      | 类型                                                                                                   | 默认值         | 说明                      |
| --------- | ------------------------------------------------------------------------------------------------------ | -------------- | ------------------------- |
| direction | `'horizontal' \| 'vertical'`                                                                           | `'horizontal'` | 排列方向                  |
| size      | `'mini' \| 'small' \| 'medium' \| 'large' \| number \| string \| [number \| string, number \| string]` | `'small'`      | 间距大小，数字单位为 `px` |
| align     | `'start' \| 'center' \| 'end' \| 'baseline'`                                                           | `'center'`     | 交叉轴对齐方式            |
| wrap      | `boolean`                                                                                              | `false`        | 是否允许换行              |
| fill      | `boolean`                                                                                              | `false`        | 是否占满父容器宽度        |

## 插槽

| 名称    | 说明                 |
| ------- | -------------------- |
| default | 需要排列的子元素列表 |
